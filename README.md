# BookVerse

BookVerse is a complete modern online bookstore website built using HTML5, CSS3, and Vanilla JavaScript. It includes a home page, a books page with search and category filters, and a contact page with form validation.

## Folder Structure

BookVerse/
├── index.html
├── books.html
├── contact.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
└── README.md

## Features

- Responsive navigation bar
- Modern hero section and featured categories
- Featured books cards with prices and ratings
- Book search and category filtering
- Comparison table on the books page
- Author, review, and FAQ sections
- Contact information cards and contact form validation
- Newsletter subscription validation
- Scroll to top button and smooth scrolling
- Modern responsive design using a single stylesheet

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run

1. Open the project folder.
2. Double-click `index.html` in a browser, or run a local server using VS Code Live Server or Python.

Example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## How to Deploy on GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository on GitHub.
3. Go to Settings → Pages.
4. Under Source, select the main branch and root folder.
5. Save the settings.
6. GitHub Pages will provide a live URL for the project.
